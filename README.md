🎮 Tic Tac Toe — 5×5 (4 in a Row)

An advanced adaptation of the classic Tic Tac Toe game developed on a **5×5 grid**, where players must strategically align **four consecutive symbols** horizontally, vertically, or diagonally to secure victory.

This project extends the traditional 3×3 format by enlarging the board and redefining the winning condition, thereby increasing complexity and strategic depth. It serves as a practical demonstration of essential programming principles, including multidimensional array manipulation, structured game-logic design, win-condition algorithms, and robust user input validation techniques.


🚀 Features

 🧩 5×5 game board offering expanded tactical gameplay
 
 🎯 Win condition: Alignment of 4 symbols in sequence
 
 👥 Two-Player mode for competitive play
 
 🤖 Player vs Computer mode with automated decision logic
 
 🔄 Structured turn-based gameplay (X vs O)
 
 ✅ Integrated move validation system
 
 🏆 Automated win and draw detection
 
 🖥️ Console-based interactive user interface
 
 

🛠️ Technologies Used

 C Programming Language
 Standard Input/Output Library
 GCC / Turbo C Compiler

🎯 Game Rules

The game is played on a 5×5 board.
Players alternately place X and O symbols.
The first player to align four consecutive symbols wins.
Valid alignments include horizontal, vertical, and diagonal patterns.
If all cells are filled without a winning sequence, the match results in a drrw.
